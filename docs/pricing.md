# DocSQL 价格体系

> 状态:建议指导价(2026-10-31 定稿)。上线前以首批 10 家目标客户支付意愿访谈校准,半年复核一次;所有合同价不得高于本公开价。
> 前提:自 v0.9.1 后新版本起采用 **AGPL-3.0 + 商业许可双授权**([许可证](../README.md#许可证) / [合规指南](compliance.md))——社区版永久免费(AGPL),商业许可 = AGPL 义务豁免 + 支持服务。

## 一、定价逻辑(为什么这么定)

1. **许可结构决定收费面**:AGPL 免费面保开发者生态,商业许可把「闭源商用」变成付费项——信创/商业客户不可能 AGPL 合规,部署即需授权;
2. **价值锚**:对标国产商业数据库(达梦/金仓/GBase 等)单节点许可一次性数万至十余万 + 年维保 15–20%;DocSQL 三年订阅总价 ≈ 它们一个节点的 license 钱,且含支持人力;
3. **成本锚**:每订阅客户的年支持成本(工单/SLA/健康检查)估 0.5–1.5 万元,订阅定价确保 70%+ 毛利;
4. **按节点计价、不按核/内存**:节点数人人看得懂,避免 CPU/内存"税基"式计价的复杂与反感;
5. **开发/测试不计费**:只对生产节点收费,降低进入摩擦,扩大部署面;
6. **公开价 = 价格上限**:透明报价建立信任,合同价 ≤ 公开价。

## 四、嵌入保障计划(OEM/ISV)

将 DocSQL 嵌入你的商业产品(闭源分发、随产品销售)——商业许可的企业形态:

| 终端部署规模 | 年费 |
|---|---|
| ≤ 1,000 实例/年 | ¥100,000 |
| 1,001–10,000 实例/年 | ¥300,000 |
| > 10,000 实例/年 | 商务定制(阶梯年费 + 5–8% 收入分成二选一) |

含:AGPL 豁免、知识产权侵权赔偿保障(以当年合同额为上限)、私有 issue 通道、版本发布前兼容性验证、季度兼容性报告。嵌入本身需要的工程改造不收费——社区版免费自测。

## 八、校准与红线

- **校准机制**:上线前访谈 10 家目标客户(国央企信创、ISV、SMB 各档)支付意愿;上线 6 个月复核转化率——低于 10% 则引入更低的「基础支持包」(¥20,000/年/集群,仅工单)做入门档;
- **红线(不可破坏的信任资产)**:
  1. 社区版功能不阉割——引擎核心(SQL/复制/备份/控制台)永远在 AGPL 开源面,商业许可卖的是法律豁免与服务,不是功能锁;
  2. 合同期内价格锁定,调价只对新约/续约生效;
  3. 公开价 = 价格上限,大客户不私下超低价破坏价格体系(破坏一次,渠道即失灵);
  4. v0.9.1 及更早版本的 Apache/MIT 不可撤销承诺如实保留——历史版本免费商用,新版本双授权。
- **开票口径**:人民币报价均为不含税价,合同注明;国央企客户按政采/框架协议挂网价 = 本公开价。
