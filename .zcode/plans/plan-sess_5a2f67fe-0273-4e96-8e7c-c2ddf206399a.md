# 补全 CRUD 测试缺口

## 1. 引擎层边界测试(crates/docsql-core/src/engine.rs `mod tests` 追加)

- `integer_boundary_values_roundtrip`:i64::MAX/MIN 插入查询、MAX+1 溢出行为、加减边界运算
- `float_precision_and_special_values`:0.1+0.2 浮点比较、负数/小数排序
- `long_string_value_survives`:~100KB 字符串插入 + LIKE/ORDER BY/等值比较
- `negative_primary_key_range_queries`:负数主键 + 索引范围查询(B+树边界)
- `string_escape_literals`:含单引号/反斜杠/中文多字节字面量往返
- `type_mismatch_insert_behavior`:往 INTEGER 声明列插字符串,钉死当前 schemaless 语义(存原值或报错,以实测行为写断言)
- `update_delete_zero_rows_reports_affected_zero`、`autoinc_after_explicit_large_id`(显式大 ID 后自增跳号)

## 2. KV 缺口

**功能小补**:kvproto.rs 增加 `EXISTS` 命令分支(返回 :1/:0),同步加 web dispatch(若适用)。
**单元测试**(docsql-kv/src/lib.rs、collections.rs):
- EXISTS 往返、DEL list/hash/zset 后 type_of 变化、DEL 在 MULTI 事务中
- TTL 边界:TTL=0/负数立即过期、过期后 EXPIRE 复活、TTL 作用于 zset/list、PERSIST 后 sweep 不删
- zset:ZADD 更新已有 member 分数、空 zset、ZRANGE min>max、zadd 到 string key 类型冲突
- kvproto arity 错误返回 RESP_ERROR

**e2e**(docsql-server/tests/e2e.rs `kv_commands_over_wire` 扩充或新增用例):DEL、EXISTS、EXPIRE/TTL/PERSIST、ZADD/ZRANGE、HSET/HGET、SADD/SMEMBERS、MULTI/EXEC/DISCARD、SET NX/XX/PX 走网络协议验证。

## 3. .NET 缺口(dotnet/Docsql.Client.Tests/AdoNetTests.cs + EF.Tests/EfTests.cs)

- 参数化 `UPDATE ... WHERE id=@id`、`DELETE ... WHERE id=@id`(ExecuteNonQuery 行数断言)
- 异步 API:ExecuteReaderAsync/ExecuteNonQueryAsync/ExecuteScalarAsync 各一例
- DataReader:GetOrdinal、NULL 列 DBNull、NextResult(若协议支持)
- EF:批量多实体 Update+Remove 一次 SaveChanges、未变更属性不产生多余 UPDATE(用 RETURNING/行数验证)
